## Everyday essentials

Type commands into Minecraft chat. Replace anything in angle brackets with your own value, without typing the brackets.

| Command | What it does |
| --- | --- |
| `/spawn` | Return to Spawn. |
| `/sethome` | Set a home at your current location. |
| `/home` | Teleport to your saved home. |
| `/tpa <player>` | Ask to teleport to a player. They must accept. |

## Travel between worlds

| Command | Destination |
| --- | --- |
| `/server blackcity` | Black City; legacy-player whitelist required. |
| `/server whiteforest` | White Forest. |
| `/server thewild` | The Wild. |
| `/end` | The End. |
| `/nether` | The Nether. |

<Info>
  Items and Pokémon carry over between realms, but **money does not**.
</Info>

## Other useful commands to try

<Note>
  These are common server commands. Availability, exact syntax, cooldowns, and limits may vary on Hikari Haven. Check in-game suggestions or ask staff if one is unavailable.
</Note>

| Command | What it does |
| --- | --- |
| `/tpaccept` / `/tpdeny` | Accept or decline a teleport request. |
| `/tpahere <player>` | Ask another player to teleport to you. |
| `/sethome <name>` / `/home <name>` | Save and visit named homes when enabled. |
| `/delhome <name>` / `/homes` | Delete a saved home or list your homes. |
| `/back` | Return to a previous location if supported; this may not include your death location. |
| `/warps` / `/warp <name>` | List and visit public warps. |
| `/rtp` | Request a random teleport where enabled. |
| `/msg <player> <message>` | Send a private message. |
| `/reply <message>` | Reply to your latest private conversation. |
| `/ignore <player>` | Hide a player's messages where supported. |
| `/balance` | Check your balance in the current realm. |
| `/cobbledollars pay <player> <amount>` | Send money if payments are enabled. Check the recipient and amount. |
| `/help`, `/rules`, `/discord` | Find help, rules, and the community link. |

<Warning>
  Only accept teleport requests from players you trust. Respect private bases and claims, and never use teleport commands to trap or harass someone.
</Warning>
