sidebarTitle: "Basic Commands"
description: "Quick reference for every essential Hikari Haven command — navigation, teleport, home management, messaging, economy, and realm travel."
---

Every command on Hikari Haven is entered directly into the Minecraft chat. Wherever you see angle brackets like `<player>` or `<amount>`, replace them with your own value — leave the brackets out when you type the actual command. The tabs below group commands by what they do so you can find what you need quickly.

<Warning>
  Only accept teleport requests from players you trust. Never use teleport commands to trap, strand, or harass another player — doing so is a rule violation and may result in a ban.
</Warning>

<Tabs>
  <Tab title="Navigation">
    | Command | What it does |
    |---|---|
    | `/spawn` | Teleport back to the Spawn town center |
    | `/sethome` | Save a home at your current location |
    | `/sethome <name>` | Save a named home (if multiple homes are enabled) |
    | `/home` | Teleport to your saved home |
    | `/home <name>` | Teleport to a specific named home |
    | `/homes` | List all your saved homes |
    | `/delhome <name>` | Delete a saved home |
    | `/back` | Return to your previous location (where supported) |
    | `/warps` | Browse all available public warp points |
    | `/warp <name>` | Teleport to a specific public warp |
    | `/rtp` | Request a random teleport into the wild (where enabled) |
  </Tab>

  <Tab title="Teleport">
    | Command | What it does |
    |---|---|
    | `/tpa <player>` | Ask to teleport to another player — they must accept |
    | `/tpahere <player>` | Ask another player to teleport to you — they must accept |
    | `/tpaccept` | Accept an incoming teleport request |
    | `/tpdeny` | Decline an incoming teleport request |
  </Tab>

  <Tab title="World Travel">
    | Command | What it does |
    |---|---|
    | `/server blackcity` | Travel to Black City (legacy/whitelisted players only) |
    | `/server whiteforest` | Travel to White Forest (open to all players) |
    | `/server thewild` | Travel to The Wild resource world |
    | `/end` | Travel to the End |
    | `/nether` | Travel to the Nether |
  </Tab>

  <Tab title="Messaging & Economy">
    | Command | What it does |
    |---|---|
    | `/msg <player> <message>` | Send a private message to a player |
    | `/reply <message>` | Reply to your most recent private conversation |
    | `/ignore <player>` | Hide messages from a player (where supported) |
    | `/balance` | Check your current realm money balance |
    | `/cobbledollars pay <player> <amount>` | Send money to another player — double-check the name and amount first |
    | `/help` | Browse available command help |
    | `/rules` | View the server rules in-game |
    | `/discord` | Get the link to the Hikari Haven Discord server |
  </Tab>
</Tabs>

<Note>
  Some commands have cooldowns or require specific rank permissions. If a command appears unavailable, try the in-game autocomplete (press Tab) or ask a staff member for guidance.
</Note>
