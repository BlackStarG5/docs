<h2>Capsules full of surprises</h2>

<p>These machines use a <strong>gacha-style capsule system</strong>: exchange the required in-game currency, receive a random capsule, then open it for a reward. They work differently from the reel-based slot game in the arcade.</p>

<h2>Using a machine</h2>

<ol><li>Check the machine’s instructions and accepted currency.</li><li>Make sure you have the required amount before using it.</li><li>Collect your capsule and open it to reveal the result.</li><li>Check what you received before deciding whether to try again.</li></ol>

<h2>What might be inside?</h2>

<p>The standard system uses <strong>Relic Coins</strong> and includes Poké, Great, Ultra, Master, and Cherish capsules. Reward pools can contain useful items such as fossils, vitamins, evolution stones, held items, and apricorns.</p>

<p>Other supported machine types may use different currencies or rewards. For example, a <strong>Rocket Prize Master</strong> uses a Koban Coin to provide a Rocket Ball containing a random Pokémon, when that machine is available.</p>

<h2>Keep it casual</h2>

<p>Hikari Haven’s approach is <strong>free-to-play fun using gameplay-earned currency</strong>. Results are random; a particular prize is never guaranteed. Read the actual machine’s cost and reward information, and do not assume Arcade Coins or CobbleDollars are interchangeable with its currency.</p>
